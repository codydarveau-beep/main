## Historical issues encountered in this restoration

- Matching disc packs had concealed stale executable-embedded title/HUD assets; exact released native extraction was necessary.
- Paperdoll/name modal batches reused the same GPU vertex prefix; restoring pixels alone could not fix this ownership bug.
- Inline buttons used a font-tint combiner despite correct button art; original native mode8 was recovered.
- Icon UVs sampled adjacent cells despite correct art; original native origin+0.5 and size-1 arithmetic was recovered.
- First palette restoration filled compass cells that runtime initialization owns; the guard caught it, and those baked cells were left blank.
- A full-canvas Willow experiment used too much per-corpse GPU memory and was rejected before production integration. Shared original layers are the active repair.
- Tutorial adaptations initially used NPC indices rather than program-owner keys; actual native negative checks caught and corrected that fixture/adapter mismatch.
- Missing reproducible arcade host ELF caused a harness failure; it now rebuilds atomically from the checked-in original assembly without mutating Source mid-test.
- A generic map-spawn reachability fixture began in a disconnected training room. The actual native combat-exam warp was recovered and used instead.
- The combined guardian test lacked its asset-path environment; that harness error was corrected. No production data was replaced to silence it.
- New delayed basic hits needed explicit sit/Play Dead cancellation. That correction was made before fresh normal integration and before either additional review.
